# photos.studiofran.co

A simple photo gallery made to show collections from trips and events.

## Structure

- `index.html`, `styles.css`, `app.js`: frontend gallery interface
- `photos/`: Image collections organized by event/album folders (with manifests and thumbnails), `/small` contains compressed photos for lazyload.
- `scripts/`: Python scripts for managing photos and generating thumbnails (easy to add new directories and large photo batches!).
